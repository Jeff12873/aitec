Importer un export GMAO

IASSITEC lit les exports CSV, Excel (.xlsx) et LibreOffice (.ods). La première ligne doit contenir les noms des colonnes.

Dans quel ordre

  1. Les machines (équipements) : repère et désignation au minimum.
  2. Les pièces (articles) : référence et désignation au minimum ; stock, seuil, fournisseur si possible ; et la colonne des équipements concernés si votre GMAO la fournit.
  3. L'historique (ordres de travail) : date et description au minimum ; machine, type, cause, intervenant, durée si possible.

Si une intervention ou une pièce cite une machine inconnue, celle-ci est créée automatiquement (avec son seul repère).

La correspondance des colonnes

IASSITEC reconnaît les intitulés courants (« Code équipement », « Qté stock », « Date début », « N° OT »…). Vérifiez chaque ligne avant d'importer : un champ peut rester « ne pas importer ». La correspondance validée est retenue : le prochain export du même logiciel sera reconnu directement.

Réimporter

Vous pouvez réimporter un export à jour à tout moment. Avec Mettre à jour les lignes déjà présentes, une machine (même repère), une pièce (même référence) ou une intervention (même n° d'OT) déjà connue est mise à jour au lieu d'être ajoutée en double. Une intervention sans numéro n'est pas ajoutée deux fois si la date, la machine et la description sont identiques.
