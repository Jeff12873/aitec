Données de la GMAO

Dans Administration › Données de la GMAO.

Directement depuis la base (le plus simple)

AITEC lit le parc et les interventions dans la base de la GMAO, par la connexion MySQL de KTEC, puis se tient à jour tout seul tous les quarts d'heure (seules les lignes nouvelles ou changées sont écrites). Deux requêtes, rangées dans le fichier de connaissances, disent où trouver les données : chacune renvoie une ligne par machine ou par intervention, avec des colonnes nommées comme les champs d'AITEC :

  • Machines : repere, designation (obligatoires), famille, marque, modele, numero_serie, emplacement, mise_en_service, etat, notes.
  • Interventions : date, description (obligatoires), numero, machine (le repère), type, cause, intervenant, duree_h, statut.

Les dates peuvent être écrites AAAA-MM-JJ, JJ/MM/AAAA ou AAAAMMJJ.

Depuis un export

AITEC lit les exports CSV, Excel (.xlsx et ancien .xls) et LibreOffice (.ods). La première ligne doit contenir les noms des colonnes.

Dans quel ordre

  1. Les machines (équipements) : repère et désignation au minimum.
  2. L'historique (ordres de travail) : date et description au minimum ; machine, type, cause, intervenant, durée si possible.

Si une intervention cite une machine inconnue, celle-ci est créée automatiquement (avec son seul repère).

La correspondance des colonnes

AITEC reconnaît les intitulés courants (« Code équipement », « Qté stock », « Date début », « N° OT »…). Vérifiez chaque ligne avant d'importer : un champ peut rester « ne pas importer ». La correspondance validée est retenue : le prochain export du même logiciel sera reconnu directement.

Réimporter

Vous pouvez réimporter un export à jour à tout moment. Avec Mettre à jour les lignes déjà présentes, une machine (même repère) ou une intervention (même n° d'OT) déjà connue est mise à jour au lieu d'être ajoutée en double. Une intervention sans numéro n'est pas ajoutée deux fois si la date, la machine et la description sont identiques.
