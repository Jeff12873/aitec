Le fichier partagé

Chaque agent a KTEC installé dans son profil, mais tous ouvrent le même fichier de connaissances .ktec sur le lecteur réseau. Il est commun à toutes les applications : AITEC, BiRTEC, PDRTec.

Comment ça marche

  • KTEC travaille sur une copie du fichier, sur le poste : c'est rapide, et ça continue de fonctionner si le réseau coupe un instant (« vous consultez la dernière copie »).
  • Toutes les 10 secondes, il regarde si le fichier partagé a changé, et recharge la copie si besoin.
  • Le poste qui modifie renvoie chaque modification vers le partage, d'un seul coup (le fichier n'est jamais à moitié écrit). Un seul poste modifie à la fois.

Ce que contient le fichier, pour AITEC

Machines, interventions, documents (les fichiers eux-mêmes), texte lu par l'IA, index de recherche, nom de l'atelier, glossaire, requêtes de synchronisation avec la GMAO, correspondances d'import. C'est une base SQLite ordinaire.

Ce qui reste sur chaque poste

Les programmes, le modèle d'IA, la copie du fichier et les réglages personnels (nom, délai de veille, conversation en cours avec l'assistant).

Le fichier n'est pas chiffré : il est protégé par les droits du dossier réseau. Ne le mettez pas dans un dossier ouvert à tous.
