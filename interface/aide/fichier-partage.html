Le fichier partagé

Chaque agent a IASSITEC installé dans son profil, mais tous ouvrent le même fichier .datassitec sur le lecteur réseau.

Comment ça marche

  • IASSITEC travaille sur une copie du fichier, sur le poste : c'est rapide, et ça continue de fonctionner si le réseau coupe un instant (« vous consultez la dernière copie »).
  • Toutes les 10 secondes, il regarde si le fichier partagé a changé, et recharge la copie si besoin.
  • En mode administrateur, chaque modification est renvoyée vers le partage, d'un seul coup (le fichier n'est jamais à moitié écrit).

Ce que contient le fichier

Machines, interventions, documents (les fichiers eux-mêmes), texte lu par l'IA, index de recherche, mot de passe (chiffré), icône, nom de l'atelier, correspondances d'import. C'est une base SQLite ordinaire.

Ce qui reste sur chaque poste

Le programme, le modèle d'IA, la copie du fichier et les réglages personnels (nom, délai de veille, conversation en cours avec l'assistant).

Le fichier n'est pas chiffré : il est protégé par les droits du dossier réseau. Ne le mettez pas dans un dossier ouvert à tous.
