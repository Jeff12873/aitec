Documents et formats lus

Déposez ici tout ce qui aide à dépanner : notices constructeur, procédures, gammes de maintenance, schémas, fiches techniques, photos de plaques signalétiques…

Ce que l'IA sait lire

  • PDF, y compris les PDF scannés : chaque page sans texte est lue par l'IA comme une image (c'est plus lent : comptez de quelques secondes à une minute par page selon le poste).
  • Photos (JPEG, PNG, WebP…) : plaques signalétiques, étiquettes, pages photographiées.
  • Word (.docx), Excel (.xlsx), PowerPoint (.pptx), LibreOffice (.odt, .ods), CSV, texte, HTML, RTF, programmes CN (.nc, .gcode).

Les autres fichiers (plans CAO, vidéos, archives, anciens .doc/.xls…) sont rangés en pièces jointes : on les retrouve depuis la liste et la fiche machine, mais l'IA ne les lit pas. Astuce : enregistrez un ancien .doc ou .xls en .docx/.xlsx ou en PDF pour qu'il soit lu.

Bien ranger

  • Choisissez la machine dans le filtre avant de déposer : les fichiers lui seront rattachés.
  • Pour changer la machine ou le nom d'un document : bouton crayon.
  • Le bouton œil montre le texte lu par l'IA, page par page, avec Traduire pour les documents en langue étrangère.
Gardez la page ouverte pendant la lecture d'un PDF : c'est le navigateur qui découpe les pages. Si la lecture est interrompue, le document reste « À lire » : bouton Lire pour recommencer.

Taille maximale d'un fichier : 900 Mo. Un même fichier déposé deux fois est signalé.
