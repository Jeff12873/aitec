Sauvegardes

Toutes les données d'AITEC sont dans le fichier de connaissances .ktec de KTEC. À chaque prise de la main sur le fichier (une fois par heure au plus), KTEC le copie dans le dossier KTEC-sauvegardes, à côté du fichier. Les 5 dernières sont gardées ; la liste est dans les Réglages de KTEC.

Revenir à une sauvegarde

  1. Demandez aux autres agents de fermer KTEC.
  2. Dans le dossier du fichier, renommez le fichier actuel (par exemple connaissances-abime.ktec).
  3. Copiez la sauvegarde voulue à côté, et renommez-la avec le nom d'origine (connaissances.ktec).
  4. Relancez KTEC.

Les sauvegardes du lecteur réseau (faites par le service informatique) protègent aussi le fichier : c'est un fichier ordinaire.
