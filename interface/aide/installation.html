Installation sur un poste

AITEC est une application de la suite KTEC : il s'installe avec KTEC, dans le profil de l'utilisateur (rien dans Program Files, aucun droit d'administrateur Windows). KTEC installe une seule fois ce que les applications partagent : le moteur d'IA et son modèle, Java et le pilote MySQL.

AITEC s'ouvre depuis le portail KTEC (sa tuile) ; on passe d'une application à l'autre par le bas du menu. La connexion MySQL est commune : le mot de passe n'est demandé qu'une fois.

Poste sans Internet

Le kit hors ligne de KTEC contient tout (programmes, moteur d'IA, modèles) et se copie sur une clé USB : rien n'est téléchargé.

Internet

Internet n'est nécessaire que pour installer (sans kit) et mettre à jour. Ensuite, tout fonctionne hors ligne : aucune donnée ne quitte le poste.

Changer de modèle d'IA

Administration › Réglages › Modèle d'IA de ce poste. Le choix vaut pour ce poste et pour toutes ses applications KTEC.
