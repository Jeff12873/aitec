Installation sur un poste

IASSITEC s'installe dans le profil de l'utilisateur : rien n'est écrit dans Program Files, et aucun droit d'administrateur Windows n'est nécessaire.

Windows

  1. Téléchargez IASSITEC.zip (page des versions du projet sur GitHub) et décompressez-le, par exemple dans Téléchargements.
  2. Double-cliquez sur Preparer IASSITEC.bat. La préparation :
    • installe IASSITEC dans %LOCALAPPDATA%\IASSITEC ;
    • analyse le poste (mémoire, carte graphique) et propose le modèle d'IA adapté ;
    • télécharge le moteur d'IA et le modèle (de 3 à 24 Go selon le modèle) ;
    • essaie l'IA et crée les raccourcis sur le Bureau et dans le menu Démarrer.
  3. Lancez IASSITEC avec son raccourci : il s'ouvre dans le navigateur.

Les modèles sont rangés dans C:\Users\Public\IASSITEC\modeles : un deuxième agent du même poste ne les télécharge pas une seconde fois.

Linux

sh preparer-iassitec.sh

IASSITEC est installé dans ~/.local/share/iassitec et ajouté au menu des applications.

Internet

Internet n'est nécessaire que pendant la préparation (et pour les mises à jour). Ensuite, tout fonctionne hors ligne : aucune donnée ne quitte le poste.

Changer de modèle

Relancez la préparation : elle propose à nouveau la liste des modèles. Les fichiers déjà téléchargés ne le sont pas une seconde fois.
