Tableau de bord

Vue d'ensemble du parc, calculée à partir des données importées. Le nom de l'atelier est en haut ; juste dessous, les boutons de parc (« Tous », ou un parc comme USINAGE ou PEINTURE) choisissent ce qui est compté. Les racines masquées dans Administration ne comptent jamais.

Les graphiques : interventions par mois (correctif, préventif, autre), types d'intervention, machines les plus en panne et dernières interventions. Les types gardent le nom qu'ils ont dans la GMAO ; leur famille (correctif, préventif, autre) se règle dans Administration › Réglages.

Ce que l'IA remarque

Le bouton Analyser fait lire les chiffres à l'IA, qui relève les points d'attention : pannes en hausse sur une machine, pannes qui se répètent, machines sans documentation… Ces remarques ne sont pas enregistrées dans le fichier : chaque poste peut les recalculer.

Les données viennent des exports GMAO importés dans l'administration. Pour une question précise sur une machine ou une panne, passez par l'Assistant IA.
