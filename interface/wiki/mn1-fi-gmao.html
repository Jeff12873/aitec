Créer et gérer les FI dans la GMAO

Admin Une FI de la GMAO porte une fiche focus. PREVTEC peut les créer, les réactiver ou les remplacer, toujours après une simulation.

Pas à pas

  1. Sur une fiche, Créer la FI : la fenêtre recalcule la charge de l'ETH en direct.
  2. Choisissez : nouvelle FI (premier numéro jamais utilisé), réactiver une FI suspendue, ou remplacer la fiche d'une FI active quand le maximum serait dépassé.
  3. Simuler : tout est exécuté dans une transaction annulée.
  4. Écrire dans la GMAO : possible seulement après une simulation réussie ; les FI sont relues juste avant d'écrire.

Réglages

  • Le bouton base de données : les paramètres des FI (choisis par leur nom), les périodicités, le SQL du site.
  • Le rouage d'un parc : son maximum de fiches par semaine et par ETH, et ce qu'il fait autrement.

L'écriture demande le compte d'écriture de la GMAO (Réglages du portail). PREVTEC n’écrit jamais sans simulation.
