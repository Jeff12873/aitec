Tableau de bord

La vue d'ensemble du parc : interventions par mois, types, machines les plus en panne, dernières interventions, et les remarques de l'IA.

Pas à pas

  1. Choisissez la zone sous le titre (ou « Tous »).
  2. Lisez les graphiques : correctif, préventif, autre par mois ; types d'intervention ; machines les plus en panne.
  3. Analyser : l'IA relève les points d'attention (pannes en hausse, pannes qui se répètent, machines sans documentation).

La famille de chaque type d'intervention (correctif, préventif, autre) se règle dans Administration › Réglages.

Trucs et astuces

  • Une machine en tête des pannes : ouvrez son analyse pour voir les pannes qui reviennent.
